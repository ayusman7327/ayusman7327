## Selected Project Experience

### Autonomous Multi-Agent Software Engineering Platform

An AI-powered development platform that translates natural-language software requirements into structured engineering workflows.

- Designed a multi-agent architecture for requirements analysis, planning, implementation, testing, and documentation
- Used LangGraph to coordinate specialized agents and workflow state
- Developed modular REST APIs with FastAPI
- Integrated PostgreSQL for persistent data management
- Prepared the application for containerized deployment with Docker
- Structured the system to support scalable software-generation workflows

**Technologies:** `React.js` `Python` `FastAPI` `LangGraph` `PostgreSQL` `Docker`

---

### Retrieval-Augmented Research Assistant

A document-based question-answering platform that generates responses using information retrieved from uploaded sources.

- Implemented document upload, text processing, and knowledge-base creation
- Built semantic retrieval with embeddings and ChromaDB
- Integrated Google Gemini for context-aware response generation
- Developed FastAPI endpoints for ingestion, retrieval, and question answering
- Organized the application as a modular RAG pipeline

**Technologies:** `Python` `FastAPI` `LangChain` `ChromaDB` `Google Gemini` `RAG`

---

### Intelligent Fraud and Threat Detection Platform

An AI-enabled security application for evaluating suspicious messages, emails, and URLs.

- Implemented SMS fraud detection, phishing-email analysis, and suspicious-URL scanning
- Applied machine-learning classification and natural-language processing techniques
- Produced interpretable predictions with fraud-risk scores
- Connected a FastAPI backend to a React-based user interface

**Technologies:** `Python` `FastAPI` `Scikit-learn` `NLP` `React`

---

### AI-Enabled Business Management Platform

A full-stack system for managing customers, products, inventory, invoices, and business insights in one place.

- Developed customer, product, inventory, and invoice-management workflows
- Added an AI assistant and an analytics dashboard
- Implemented JWT-based authentication and protected routes
- Integrated MongoDB for application data storage

**Technologies:** `React` `Node.js` `Express.js` `MongoDB` `JWT` `Google Gemini`

---

### Personal Finance Management Platform

A secure personal-finance application for tracking income, expenses, budgets, and investments.

- Developed an investment dashboard with interactive charts and analytics
